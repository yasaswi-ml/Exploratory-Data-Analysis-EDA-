# 📊 Exploratory Data Analysis (EDA)

This repository contains my notes, code, and practical implementations of Exploratory Data Analysis (EDA) using Python.

I'm building this as a reference for my Machine Learning journey, covering different ways to explore datasets, understand feature distributions, find relationships between variables, identify missing values and outliers, and draw useful insights before training ML models.

## 🛠️ Libraries Used

| Library | Purpose |
|---|---|
| Pandas | Data manipulation and analysis |
| NumPy | Numerical operations |
| Matplotlib | Data visualization |
| Seaborn | Statistical data visualization |

## 📚 Topics Covered

### 1. Data Understanding
- Loading datasets.
- Checking the number of rows and columns.
- Exploring column names and data types.
- Viewing the first and last few records.
- Generating statistical summaries.
- Checking unique values.

### 2. Statistical Analysis

**Central Tendency**
- Mean
- Median
- Mode

**Measures of Dispersion**
- Range
- Variance
- Standard Deviation
- Interquartile Range (IQR)
- Mean Absolute Deviation (MAD)

**Distribution Measures**
- Skewness
- Kurtosis
- Percentiles
- Quartiles

### 3. Univariate Analysis

Analyzing one variable at a time to understand its distribution and characteristics.

- Histograms
- Boxplots
- KDE plots
- Countplots
- Pie charts
- Frequency distributions

### 4. Bivariate Analysis

Analyzing two variables to understand how they are related to each other.

- Scatterplots
- Correlation analysis
- Boxplots
- Violin plots
- Bar plots
- Cross-tabulation (Crosstab)

### 5. Multivariate Analysis

Analyzing three or more variables together to understand complex relationships and patterns.

- Correlation heatmaps
- Pairplots
- Multivariable scatterplots
- Grouped feature analysis
- PCA visualization

### 6. Data Quality Analysis

Checking the dataset for issues that might affect further analysis or model training.

- Identifying missing values.
- Checking missing value percentages.
- Finding duplicate records.
- Detecting outliers using the IQR method.
- Identifying constant features.

### 7. Data Visualization

Using different visualization techniques to understand patterns and distributions.

- Histograms
- Boxplots
- Scatterplots
- Countplots
- Pie charts
- KDE plots
- Pairplots
- Correlation heatmaps

### 8. Data Cleaning

Basic techniques for handling issues identified during data exploration.

- Handling missing values.
- Removing duplicate records.
- Replacing incorrect values.
- Filtering unwanted observations.
- Handling outliers.
- Correcting data types.

## 🔄 Where EDA Fits in Machine Learning

EDA helps us understand what we're working with before jumping into model development.

The general workflow looks like this:

```text
Raw Dataset
     |
     ▼
Data Understanding
     |
     ▼
Exploratory Data Analysis
     |
     ├── Statistical Analysis
     ├── Univariate Analysis
     ├── Bivariate Analysis
     ├── Multivariate Analysis
     └── Data Visualization
     |
     ▼
EDA Insights
     |
     ▼
Data Cleaning
     |
     ▼
Data Preprocessing
     |
     ▼
Feature Engineering
     |
     ▼
Model Training & Evaluation
```
